HPC examples

A growing collection of ready-to-run examples on the HPC cluster RUDENS. Each repository has its own README with the exact commands to clone, build and submit.

Prerequisite: an active RTU HPC (RUDENS) allocation (see Request HPC resource) and a working cluster connection (see Connect to the HPC cluster).

Examples for educational purposes

  • HPC introductory examples — introductory tasks covering job submission, parametric array jobs, CUDA, MPI, and a toy GPT (LLM). Contributed by Lauris Cikovskis.

  • Rotating propeller CFD — coupled CFD and structural analysis of a rotating propeller using ANSYS Fluent. Contributed by Sabine Upnere.

  • Water-gravity flow simulation — Mantaflow water simulations in Blender, run headless on the cluster Contributed by Maris Kalinka.

  • OpenCL parallel linear algebra — GPU-vs-CPU benchmarks for vector sum, matrix multiplication and Gauss elimination. Contributed by Igor Schukin.
